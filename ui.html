PC & Roblox Requirements

PC Settings

Your PC must be configured with these exact settings for the macro to work correctly:

Display Resolution • 1920x1080 (Full HD) - Recommended
• Other compatible resolutions may work but require custom coordinate setup
• Lower resolutions will cause placement issues

Display Scale • Must be set to 100%
• Any other scale (125%, 150%, etc.) will break coordinate detection
• Check: Settings → System → Display → Scale

Critical • Both settings are mandatory for proper macro functionality
• Incorrect settings will result in misplaced units and navigation failures

Roblox Settings

Configure Roblox with these exact settings in-game:

Graphics Settings • Graphics Mode: Manual
• Graphics Quality: Lowest (1)
• This ensures consistent performance and button detection

Frame Rate • FPS Cap: 60 FPS
• Do not uncap or use higher frame rates
• Stable frame rate improves macro reliability

Camera Settings • Camera Sensitivity: 0.2
• This is critical for consistent camera positioning
• Check: Settings → Camera → Mouse Sensitivity

Text Settings • Text Size: Default
• Do not increase or decrease text size

Prohibited • No Bloxstrap - Custom fonts break button detection
• No Extension Fonts - Use default Roblox font only
• No Discord Overlay - Disable all overlays
• No Other Overlays - Steam, Xbox Game Bar, etc.

Important Notes • All settings must be applied before starting the macro
• Changes during macro execution will cause failures
• Verify settings each time you launch Roblox

AP Settings

These are the in-game Anime Paradox settings that must be configured for the macro to work properly:

Required Settings • Configure these settings exactly as shown in the images above
• Incorrect AP settings will cause macro navigation failures
• Verify these settings before each macro session

Verification Checklist

Before starting the macro, verify all requirements:

□ PC display resolution is 1920x1080
□ PC display scale is 100%
□ Roblox graphics set to Manual + Lowest
□ Roblox FPS capped at 60
□ Roblox camera sensitivity is 0.2
□ Roblox text size is default
□ No Bloxstrap or custom fonts active
□ All overlays (Discord, Steam, etc.) disabled
□ AP settings configured as shown above

Once all items are checked, you're ready to use the macro!

Unit Configuration Details

Unit Properties Explained

On (Enabled)
• Checkbox to enable/disable this unit
• Disabled units are skipped during macro execution
• Useful for temporarily testing different setups

Early (PlaceBeforeYes)
• Places unit BEFORE clicking the start button
• Essential for farming units that need early placement
• Use for units that generate resources from the start
• Camera positioning happens before early units are placed

Auto⬆ (AutoUpgrade)
• Automatically clicks the Auto Upgrade button in the unit UI
• Continues upgrading until target level is reached
• Set Upgrade level to Max for continuous upgrading
• More reliable than manual T key pressing

Ability (AutoAbility)
• Automatically activates the unit's ability after placing/upgrading
• Clicks the ability button before closing the unit panel
• Enable for units that benefit from ability activation
• Independent toggle for each individual unit

Action
• Dropdown to choose what this unit slot does: Place, R-Click, or Wait For
• Place (default) — Normal unit placement using hotkey + click at coordinates
• R-Click — Right-clicks at the specified X/Y coordinates to move your character using Roblox's "Click to Move" movement setting. Useful for repositioning during a match without placing a unit
• Wait For — Pauses macro execution for the specified number of seconds. No coordinates or slots needed
• Changing Action hides/shows relevant fields (Slot, Upgrade, Seconds, X/Y)

Slot
• Hotkey slot number (1-6) where unit is equipped
• Set to 0 for units that need clicking to place/upgrade
• Slot 0 is also used when upgrading existing units
• Make sure your in-game hotkeys match these numbers
• Hidden when Action is R-Click or Wait For

Upgrade
• Target upgrade level (0 = no upgrade, 1-5 = specific level, Max = max level)
• Combined with AutoUpgrade, clicks auto upgrade button until level reached
• Without AutoUpgrade, will attempt single upgrade
• Max setting continues upgrading indefinitely
• Hidden when Action is R-Click or Wait For

Seconds (Wait For only)
• Number of seconds to pause macro execution
• Only visible when Action is set to "Wait For"
• Supports decimal values (e.g., 2.5 seconds)
• Macro can still be stopped with F3 during the wait

X / Y Coordinates
• Pixel coordinates for unit placement or right-click on screen
• Must be accurate for proper placement
• Use coordinate picker for best results
• Coordinates are relative to your screen resolution
• Hidden when Action is Wait For (not needed)

Note
• Optional text field for your reference
• Write unit name, strategy notes, or reminders
• Helps organize complex configurations

Creating & Using Presets

What Are Presets?

Presets are reusable action sequences that can be assigned to units. Instead of configuring complex action sequences for each unit individually, you can create a preset once and apply it to multiple units.

Benefits of Presets:
• Create complex action sequences once, reuse many times
• Quickly test different strategies by swapping presets
• Share presets between different configs easily
• Simplify unit configuration with preset dropdown selection
• Keep action sequences consistent across multiple units

When to Use Presets:
• Multiple units need the same action sequence
• Complex multi-step actions (target, wait, reposition, etc.)
• Frequently adjusted strategies during testing
• Sharing configurations with others

Creating a New Preset

Step 1: Open Preset Editor
• Go to the Presets tab in the main interface
• You'll see a list of existing presets on the left
• Click + New Preset button at the bottom

Step 2: Name Your Preset
• Enter a descriptive name (e.g., "DPS_Aura_Combo", "Farmer_Early")
• Use names that describe the preset's purpose
• Preset names appear in unit dropdown selectors

Step 3: Add Actions
• Click + Add Action to create action slots
• Each action is a step that will be executed in order
• Configure each action using the dropdowns and inputs
• You can add as many actions as needed

Step 4: Configure Actions
• Select action Type from the dropdown
• Fill in required fields based on action type
• Test your preset by assigning it to a test unit

Step 5: Save Preset
• Click Save Preset button
• Preset is now available in all unit config dropdowns
• You can edit or delete presets anytime

Available Action Types

Wait
• Pauses macro execution for a specified duration
• Duration (seconds): How long to wait (supports decimals)
• Useful for timing between actions or cooldowns
• Example: Wait 2.5 seconds before next action

Type Text
• Types text into the currently focused input field
• Text: The text to type (e.g., upgrade command)
• Ensure the correct input is focused before this action
• Useful for chat commands or custom inputs

Reposition
• Moves your character using WASD directional hold
• Key: Choose W (forward), A (left), S (backward), or D (right)
• Hold Duration (seconds): How long to hold the key (supports decimals)
• Useful for adjusting unit placement or character position mid-match
• Example: Hold W for 1.5 seconds to move character forward
• Important: This moves YOUR CHARACTER, not the unit. Use for positioning yourself before placing units or during match

Click
• Clicks at absolute screen coordinates
• X: Horizontal pixel position
• Y: Vertical pixel position
• Use coordinate picker to find exact coordinates
• Good for clicking custom UI elements or buttons

Example Preset Configurations

Example 1: "Reposition_Forward"
1. Reposition — Key: W, Hold Duration: 2.0 seconds
2. Wait — Duration: 0.5 seconds
→ Moves character forward for better unit placement position, then waits to stabilize

Example 2: "Side_Step_Left"
1. Reposition — Key: A, Hold Duration: 0.8 seconds
2. Wait — Duration: 0.3 seconds
→ Moves character left slightly, then stabilizes

Example 3: "Complex_Combo"
1. Reposition — Key: D, Hold Duration: 1.0 second
2. Wait — Duration: 0.3 seconds
3. Click — X: 1200, Y: 650 (custom button)
4. Wait — Duration: 1.0 seconds
5. Click — X: 1300, Y: 700 (another button)
→ Repositions character, clicks custom UI elements with timing

Example 4: "Ability_Sequence"
1. Wait — Duration: 1.5 seconds
2. Click — X: 1100, Y: 600 (ability button)
3. Wait — Duration: 0.5 seconds
→ Waits for unit to be ready, then activates ability

Using Presets in Unit Config

Once you've created presets, assign them to units:

Step 1: Open Unit Configuration
• Go to the Units tab
• Find the unit you want to configure

Step 2: Select Preset
• Find the Preset dropdown for that unit
• Click the dropdown to see all available presets
• Select the preset you want to use
• "None" option means no preset actions will execute

Step 3: Save Configuration
• Click Save Config at the bottom
• Preset is now assigned to that unit
• When macro runs, it will execute preset actions after placing/upgrading the unit

⚠️ Missing Preset Error:
If you load a config that references a preset you don't have, you'll see an error message:
"Missing presets: "PresetName" (used by Unit X). Create them in Preset Editor."
→ Create the missing preset or change the unit's preset to an existing one

Managing Presets

Editing a Preset
1. Go to Presets tab
2. Click the preset name in the list
3. Modify actions as needed (add, remove, or change)
4. Click Save Preset
5. All units using this preset will use the updated version

Deleting a Preset
1. Select the preset in the list
2. Click Delete Preset button
3. Confirm deletion
4. Warning: Units using this preset will show errors. Reassign them to different presets or "None"

Renaming a Preset
1. Select the preset
2. Delete it (it saves the actions)
3. Create a new preset with the desired name
4. Add the same actions back
5. Reassign units to the new preset name

Duplicating a Preset
1. Open the preset you want to duplicate
2. Note down all its actions
3. Create a new preset with a different name
4. Add the same actions
5. Modify as needed for the new use case

Preset Best Practices

✓ DO:
• Use descriptive preset names ("Reposition_Forward" not "preset1")
• Test presets with a single unit before applying to many
• Keep presets focused on specific strategies
• Create separate presets for different unit roles
• Document complex presets with clear naming
• Use Wait actions between rapid clicks to ensure stability
• Save presets before making major changes

✗ DON'T:
• Make presets too complex (split into multiple presets instead)
• Delete presets that are actively used in configs
• Use vague names that don't describe the preset's purpose
• Assume presets work without testing first
• Add too many actions without testing incrementally
• Forget to save after making changes

💡 Tips:
• Start with simple presets and gradually add complexity
• Reposition actions are great for character movement, not unit placement
• Wait actions help synchronize timing between actions
• Use Click actions for precise UI interactions and custom buttons
• Keep backup copies of working presets (export configs to preserve them)
• Test presets in lower-stakes scenarios before using in important runs

Troubleshooting Presets

Preset actions not executing
✓ Ensure preset is saved (check Presets tab)
✓ Verify unit has preset selected in dropdown
✓ Check macro status log for error messages
✓ Test with simpler preset to isolate issue

Actions executing in wrong order
✓ Actions execute top-to-bottom in the preset editor
✓ Reorder actions by deleting and recreating them
✓ Add Wait actions between steps to ensure proper timing

Reposition action not moving character
✓ Verify character is not blocked by terrain or units
✓ Check Hold Duration is long enough (try 1.0+ seconds)
✓ Ensure game is focused and not minimized
✓ Test with different WASD keys to confirm movement

Click actions missing target
✓ Use coordinate picker to verify X/Y values are correct
✓ Ensure game resolution hasn't changed
✓ Add Wait action before Click to ensure UI is loaded
✓ Check if target UI element moved or changed size

Missing preset error when loading config
✓ Create the missing preset in Preset Editor
✓ Or change units to use existing presets
✓ Check preset name matches exactly (case-sensitive)
✓ Import preset files if you received them from others

How to Import Configs

Importing configs allows you to load unit configurations created by others or transfer configs between installations. Follow these simple steps:

Step 3: Select Config File
• Navigate to the folder containing your config file
• Config files have a .json extension
• Double-click on the config file you want to import
• Alternatively, single-click to select it, then click the Open button

Step 4: Config Loaded
• The config will be imported immediately
• Unit configuration will update to match the imported file
• The macro's Mode, Location, and Act will also update to match the imported config
• You can now review the units and their settings
• Make any adjustments if needed
• Click Save Config to save the imported settings

Important Notes

⚠️ Preset Dependencies

• Imported coordinates are absolute pixel positions
• They may not work if your screen resolution is different

⚠️ Mode/Location Sync
• Import automatically updates the backend config to match

⚠️ Custom Mode
• When importing Custom mode configs, ensure the custom location exists
• If the custom location doesn't exist, you'll need to create it
• Go to Custom mode dropdown and create the matching location name

✓ Backup Your Configs

• You can manually copy JSON files from the Settings folder
• Or use the Import feature to save your current config elsewhere first

Image Match Tolerance

The macro uses image detection to find buttons and UI elements. Tolerance controls how closely images must match:

Understanding Tolerance
• Higher tolerance (0.8-0.95): More strict matching, fewer false positives
• Lower tolerance (0.4-0.6): More flexible matching, better for inconsistent UI
• Default: 0.65 (balanced for most situations)

Average Tolerance Setting
1. Go to Settings tab
2. Check "Use Average Image Match Tolerance"
3. Adjust slider between 0.4 and 0.95

FAQ

Q: Can I use multiple configs for the same stage?
A: Each Mode/Location/Act has one config. You can manually backup configs by copying the JSON files from the Settings folder.

Q: What's the difference between Slot 0 and Slot 1-6?
A: Slots 1-6 use hotkeys to place units. Slot 0 means clicking the unit on screen to place/upgrade it.

Q: How many units can I configure?
A: Up to 30 units per configuration. Enable only the ones you need.

Q: Can I pause the macro?
A: Press F3 to stop the macro. Resume by pressing F1 (it will start from the beginning).

Q: Does the macro work on all screen resolutions?
A: Coordinates are absolute pixels, so configs are resolution-specific. Create separate configs for different resolutions.

Q: What if a new update changes the game?
A: You may need to retake screenshots and update coordinates. Button images may also need updating.

Q: Is there a way to debug my config?
A: Watch the status log in real-time. Enable one unit at a time to identify problematic units.
